Read this before trusting the numbers

These are declared values, not invoices. When someone applies for a permit, they state an estimated project value up front — before the work starts — and permit fees scale with that number, so declared values tend to run below what the job finally costs. Treat them as a market anchor, not a quote.

Only permitted work is counted. Jobs done without a permit (a large share of small repairs) never appear here, and withdrawn permits are excluded. Figures cover 94 permitted jobs filed Jul 2026 – Oct 2026 and are refreshed daily from public records; the middle 50% range is a better budgeting guide than any single number.
